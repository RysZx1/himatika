# 🌐 Portal Web HIMATIKA UUI

Website resmi Himpunan Mahasiswa Informatika (HIMATIKA) yang berfungsi sebagai pusat informasi akademik, dokumentasi kegiatan, dan forum diskusi mahasiswa. Dibangun dengan menggunakan arsitektur VILT Stack (Vue.js, Inertia.js, Laravel, Tailwind CSS) yang modern dan reaktif.

## ✨ Fitur Utama

- **Landing Page Interaktif**: Dilengkapi dengan animasi *3D Cyber Network Canvas* yang responsif pada Hero Section.
- **Role-Based Access Control (RBAC)**: Sistem autentikasi multi-level (Super Admin, Pengurus, Mahasiswa).
- **Admin Panel Terintegrasi**: 
  - 📰 **Kelola Berita**: Pembuatan artikel dan berita dengan fitur upload thumbnail.
  - 📸 **Galeri Dokumentasi**: Manajemen foto kegiatan himpunan dengan fitur *Lightbox Zoom*.
  - 📅 **Informasi Rapat**: Penjadwalan rapat internal/terbuka beserta arsip unduhan Notulensi (PDF/Doc).
- **Community Feed**: Forum diskusi interaktif ala sosial media khusus untuk mahasiswa Informatika.
- **Modern UI/UX**: Navigasi mulus (*Smooth Scrolling*), Pop-up Modal interaktif, dan notifikasi *Alert* kustom yang estetis.

## 🛠️ Tech Stack

- **Backend**: [Laravel 11](https://laravel.com/) (PHP)
- **Frontend**: [Vue.js 3](https://vuejs.org/) (Composition API)
- **Connector**: [Inertia.js](https://inertiajs.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Database**: MySQL / SQLite (Bawaan Laravel)
